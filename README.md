Weather Dashboard:
A responsive weather dashboard built using HTML, CSS, and JavaScript that provides real-time weather information for any city. The application integrates with the OpenWeatherMap API to fetch and display current temperature, weather conditions, humidity, and wind speed. It features a clean user interface, dynamic data updates, and error handling for invalid locations.

Features:

Search weather by city name
Real-time weather data using OpenWeatherMap API
Displays temperature in Celsius
Shows weather description and conditions
Displays humidity and wind speed
Responsive and user-friendly interface
Error handling for invalid city names

Technologies Used:

HTML
CSS
JavaScript 
OpenWeatherMap API

Project Structure:

index.html – User interface and page structure
style.css – Styling and responsive design
app.js – API integration and dynamic weather updates

How It Works:

User enters a city name.
JavaScript sends a request to the OpenWeatherMap API.
Weather data is retrieved and processed.
Temperature, weather condition, humidity, and wind speed are displayed on the dashboard.
If the city is invalid, an error message is shown.
